# Local broker snapshot connector

Run from Windows PowerShell in the repository root. Install Python 3.10+ and run `py -m pip install kiteconnect`. For Paytm, follow the official SDK installation at https://github.com/paytmmoney/pyPMClient and make its module available in the same Python environment. Run `py broker_sync.py`. Create API credentials in the official developer portals and register a redirect URL you control. Login in the broker website and paste the redirect URL into the hidden terminal prompt. Paytm requires the returned callback state to match; if the SDK or callback differs, stop and verify the provider documentation. Never paste secrets in chat or commit them. Snapshot files are written under your home directory in PortfolioBrokerSnapshots; keep that directory private and outside synced folders. In the PWA Import/Data tab select the JSON snapshot. Current implementation reviews Zerodha holdings only; Paytm normalization, historical trades, live bridge, reconciliation and automated synchronization are pending. No trading endpoints are called. Live authentication requires real broker credentials and has not been tested.

## Direct Zerodha synchronization (Windows only)
Run `py broker_server.py`, authenticate in the official login, then open http://127.0.0.1:8765 in your browser. Under Import/Data enter the temporary pairing key printed in the terminal and click Fetch Zerodha holdings. Keep the terminal running. Restart it to reconnect after session expiry. This origin has separate browser storage: export your existing portfolio backup and restore it here if needed. Do not expose the server to the LAN or internet. Paytm direct API and iPhone access are not implemented. Broker results are review-only and not cached by the service worker. Live authentication and browser integration have not been tested.
